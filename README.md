\# Server Uptime Monitoring System



A Python Flask-based Server Uptime Monitoring System with Machine Learning-based Anomaly Detection.



\## About the Project



The Server Uptime Monitoring System is a Python-based application designed to monitor server availability and analyze server logs.



It uses Flask for the web application and Scikit-learn for machine learning-based anomaly detection.



\## Technologies Used



\- Python

\- Flask

\- SQLite (database component)

\- Scikit-learn

\- Requests

\- HTML

\- CSS

\- JavaScript

\## Installation and Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/krrishprashar7-lab/Server\_Uptime\_Monitor.git

```



\### 2. Navigate to the Project Directory



```bash

cd Server\_Uptime\_Monitor

```



\### 3. Create a Virtual Environment



```bash

python -m venv venv

```



\### 4. Activate Virtual Environment



For Windows:



```bash

venv\\Scripts\\activate

```



\### 5. Install Dependencies



```bash

pip install -r requirements.txt

```



\### 6. Run the Application



```bash

python app.py

```



\### 7. Open in Browser



```text

http://127.0.0.1:5000

```
